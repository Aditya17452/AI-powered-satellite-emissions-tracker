# AI-SET — AI-Powered Satellite Emission Tracker

Industrial air-quality monitoring and forecasting dashboard. Serves a 72-hour pollutant
history, a 72-hour LSTM forecast, CPCB-style air-quality classification, Isolation Forest
anomaly detection, and nearest-source industry attribution through a Flask JSON API with a
browser dashboard.

**Top 10 National Finalist — Clear Skies Challenge 2025, GeoSmart India (IIT Tirupati),
among 100+ teams.**

---

## What it does

| Capability | How |
|---|---|
| 72-hour pollutant history | Hourly PM2.5 / PM10 / CO₂ series with diurnal cycling, deterministic per coordinate |
| 72-hour forecast | Keras LSTM (`models/lstm_pollution_model.h5`), with an AR(1) random-walk fallback if the model is absent or the input shape mismatches |
| Air-quality classification | CPCB-style bands — Good, Satisfactory, Moderate, Poor, Very Poor, Severe — for each pollutant |
| Anomaly detection | Isolation Forest (`models/isolation_forest_model.pkl`) over the `[PM2.5, PM10, CO₂]` vector |
| Source attribution | Dominant pollutant identified, then nearest industry in the catalog that emits it |
| Date-targeted prediction | Any date inside the 72-hour horizon resolves to the nearest forecast hour; beyond it, the last step is carried forward |

The LSTM loader adapts the input tensor to whatever shape the saved model expects — it trims
or left-pads the timestep axis and, when the model wants more than three features, derives
cyclical hour/day-of-week encodings and 3-hour rolling means to fill the gap. Prediction
output is normalised back to a `(72, 3)` array regardless of the model's output rank.

## Running locally

```bash
git clone https://github.com/Aditya17452/AI-powered-satellite-emissions-tracker.git
cd AI-powered-satellite-emissions-tracker

python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

pip install flask tensorflow scikit-learn numpy joblib
python app.py
```

Open `http://127.0.0.1:5000`. Both models load at startup; the app degrades gracefully and
keeps serving if either file is missing.

## API

### `GET /health`
```json
{ "ok": true, "lstm_loaded": true, "iso_forest_loaded": true }
```

### `POST /predict`

Request:
```json
{ "city": "Varanasi", "lat": 25.3176, "lon": 82.9739, "date": "2025-08-25" }
```

Response:
```json
{
  "city": "Varanasi",
  "coords": { "lat": 25.3176, "lon": 82.9739 },
  "history_72h": [ { "timestamp": "...", "PM2_5": 82.4, "PM10": 151.7, "CO2": 903.2 } ],
  "current_status": {
    "PM2.5": { "value": 82.4,  "status": "Moderate" },
    "PM10":  { "value": 151.7, "status": "Moderate" },
    "CO2":   { "value": 903.2, "status": "Satisfactory" }
  },
  "future_72h": [ { "timestamp": "...", "PM2_5": 79.1, "PM10": 148.3, "CO2": 898.6 } ],
  "prediction_on_date": { "timestamp": "...", "PM2_5": 77.0, "PM10": 145.2, "CO2": 890.1, "classified": {} },
  "industry": { "name": "Shiv Shakti Steel", "lat": 25.35, "lon": 82.97, "pollutants": ["PM2.5", "PM10"] }
}
```

`lat` and `lon` are required and must be numeric; `city` and `date` are optional.

### `POST /anomaly`

```json
{ "values": [82.4, 151.7, 903.2] }
```
```json
{ "anomaly": false }
```

Returns `503` when the Isolation Forest model is not loaded.

## Classification thresholds

| Band | PM2.5 (µg/m³) | PM10 (µg/m³) | CO₂ (ppm) |
|---|---|---|---|
| Good | ≤ 30 | ≤ 50 | ≤ 450 |
| Satisfactory | ≤ 60 | ≤ 100 | ≤ 1000 |
| Moderate | ≤ 90 | ≤ 250 | ≤ 2000 |
| Poor | ≤ 120 | ≤ 350 | ≤ 5000 |
| Very Poor | ≤ 250 | ≤ 430 | — |
| Severe | > 250 | > 430 | > 5000 |

## Data note

The LSTM was trained on Sentinel-5P atmospheric data accessed via Google Earth Engine,
reaching R² ≈ 0.89 on held-out pollution forecasting. The Isolation Forest was validated on
constructed test scenarios because labelled industrial-anomaly data is scarce.

This repository ships the **demo server**: the 72-hour history it serves is generated by a
coordinate-seeded synthetic generator rather than a live Earth Engine pull, so the dashboard
runs offline and reproducibly for evaluation. The trained models, forecasting pipeline,
classification logic and anomaly detection are the real artifacts. Live satellite ingestion
is the next milestone below.
